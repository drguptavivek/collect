# Scanning Draft Form QR Codes

The **MEDRES ODK Collect** app supports a special **"Demo Mode"** that allows users to test ODK Central Draft forms without requiring a full App User account or official project configuration.

## 1. What is a Draft QR Code?
A Draft QR code is generated by ODK Central for testing a specific form during development.

**Key Characteristics:**
- **Contains `/draft` and `/test/`**: The URL structure includes `.../v1/test/<TOKEN>/projects/.../draft`.
- **No Private Key**: Unlike App User QRs, it does not contain a long-lived API key.
- **Temporary**: The token is intended for testing only.
- **Form-Centric Display Metadata**: In Draft QRs, the `project` object is used as display metadata for the draft form context. In practice, `project.name` is the draft form label shown to the user, not the durable MEDRES project name to persist into production configuration.

### JSON Structure
```json
{
    "general": {
        "server_url": "https://SERVER/v1/test/TOKEN/projects/PID/forms/FID/draft",
        "form_update_mode": "match_exactly",
        "autosend": "wifi_and_cellular"
    },
    "project": {
        "name": "[Draft] Form Name",
        "icon": "📝"
    },
    "admin": {}
}
```

### Important Interpretation Rule

For Draft QRs:
- `project.name` should be treated as a **display label** for Demo Mode, typically the draft form name.
- The real Central `project_id` should be derived from the `server_url` path if needed.
- Draft QR metadata must **not** overwrite the persistent MEDRES project identity used for normal login and production data collection.

## 2. How to Scan
There are two ways to enter Demo Mode:

### Method A: Auth Settings (Preferred)
1.  Go to **Main Menu** -> **Auth Settings** (Gear/Shield Icon).
2.  Scroll down to the **"Scan Demo QR (Native)"** button.
3.  Scan the Draft QR Code.
4.  The app will:
    - Detect the Draft URL.
    - Wipe any existing authentication session.
    - Enter **Demo Mode**.

### Method B: Login Screen Rescue
1.  If you accidentally scan a Draft QR using the system camera or generic scanner, you might land on the Login Screen with an "Invalid Project" error.
2.  The app will detect the Draft URL and display a large **"Enter Demo Mode"** button.
3.  Click it to bypass login.

## 3. Intelligent QR Detection
The scanner implements strict logic to keep your app safe:

| QR Type | Marker | Action |
| :--- | :--- | :--- |
| **Draft / Test** | Contains `/draft` **AND** `/test/` | **ACCEPTED** -> Enters Demo Mode |
| **MEDRES Project** | Clean URL (e.g. `/v1/projects/3`) | **ACCEPTED** -> Standard Login |
| **Standard ODK User** | Contains `/key/` (but no `/test/`) | **REJECTED** -> "Standard ODK QR Rejected" |

**Why reject Standard ODK QRs?**
This prevents you from accidentally overwriting your secure Medres configuration with an incompatible standard ODK App User token, which would break the custom authentication flow.

## 4. Persistence Rules

Draft QRs are intended to open an isolated Demo Mode context for testing forms. They must not be treated as normal project-onboarding QRs.

| Field | How to Interpret | Persistence Rule |
| :--- | :--- | :--- |
| `general.server_url` | Draft form launch URL | Used to detect Demo Mode and derive identifiers |
| `project.name` | Draft form display label | Display only; do not persist as the real MEDRES project name |
| `project.icon` | Demo Mode display hint | Display only |
| Project ID | Derived from URL path | Use only for draft/demo context binding |
| `admin` | Usually empty in draft QRs | Do not assume normal project admin lock import |
